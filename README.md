# G.A.S.P
**Gabe's Amazing Screenshot Program**

GASP is a precision, pixel-perfect screenshot tool designed specifically for Power BI Desktop. It uses an intelligent "Seeker" algorithm to identify visual borders and capture them with 100% accuracy.

## ✨ Key Features
*   **Pixel-Perfect Seeker**: Automatically finds the `#C8C8C8` selection border of any visual.
*   **Global Hotkey**: Press `Alt + S` to trigger a capture from anywhere.
*   **Zero-Fuss Install**: Registers itself in the Power BI "External Tools" ribbon without requiring Admin rights.
*   **Minimalist UI**: Lightweight on memory, runs quietly in your System Tray.
*   **Flexible Workflow**: Choose to instantly copy to your clipboard or save to a file.

## 🚀 Quick Start
1.  Launch **`GASP_Local.exe`**.
2.  Configure your preferences (Color, Tolerance, Action).
3.  Click **"Install & Save Config"**.
4.  Click **"Minimize to Tray"**.
5.  In Power BI, select a visual and hit **`Alt + S`** (or use the button in the External Tools ribbon).

## 🛠 Troubleshooting
*   **Icon not showing?** Ensure the app is running in the system tray.
*   **Not detecting visual?** Make sure the visual is **selected** (has the grey border) before triggering the capture.
